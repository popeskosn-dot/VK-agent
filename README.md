# VK Agent

Мини-приложение для публикации постов на личную стену ВКонтакте.

## Как работает

Приложение использует VK Bridge и официальный вызов `VKWebAppShowWallPostBox`. ВКонтакте показывает стандартное окно подтверждения публикации.
